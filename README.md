# introduction

hello! this is something little i made for myself for use in various unix-likes. its a CLI diary (plaintext to base 64) that's meant to run automatically every evening.
- good if you (really!) want to write a diary but are often too busy to remember that you (really!) want to write a diary
- good if you want to write down things without rereading them conveniently 

# prerequisites

1. add a .diary directory to your home
2. (optional but highly recommended) add this as an alias to your ~/.bashrc or ~/.zshrc
3. (optional) set this script to run everyday at 7pm-ish instead of running manually
